## 标准提示词字段

```text
ID / 标题
适用场景
生成模式与画幅
参考素材职责
时间轴或动作节拍
摄影路径与焦点
声音设计
一致性约束
禁止项
```

建议从最接近目标的场景开始，仅替换主体、场景、动作和结尾。先验证身份与产品几何，再增加复杂运镜、特效、声音或多人互动。
