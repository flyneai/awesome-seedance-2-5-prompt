## 每次测试记录

复制以下模板，填写真实结果。不要上传账户信息或私密素材。

```text
Test ID:
Date:
Operator:
Provider: Flyne AI
Model label visible in the interface:
Source recipe / case ID:
Exact submitted prompt:
Input files and their roles:
Input rights / attribution:
Duration / ratio / resolution / audio:
Other settings, including seed if available:
Displayed cost:
Actual charged cost (if known):
Public output URL or authorized output file:
Observed defects:
What changed from the previous attempt:
Verdict: usable / needs revision / failed
Reviewer and review date:
```

只有填写实际提示词、输入、设置、输出和检查结果后，才能发布为实测案例。保留失败或需要修改的记录，避免只展示成功结果。实测输出应单独标注为 Flyne AI 生成，不要与外部 X 视频混用。

An entry becomes a tested example only after its exact inputs, settings, output and review are recorded. Planning a test, opening the generator, or checking a media URL does not count as running it.
